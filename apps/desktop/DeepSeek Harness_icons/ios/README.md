# iOS 图标包说明（iOS 18 Ready）

## 📱 iOS 18 新特性支持
本包完全支持 iOS 18 的新图标系统，包含以下三种外观变体：
- **Light Mode (Any)**: 标准亮色模式图标
- **Dark Mode**: 深色模式优化版本（降亮度25%）
- **Tinted Mode**: 系统主题色着色版本（白色轮廓）

## 📦 包含内容
### 1. AppIcon.appiconset (iOS 18格式)
- `icon-any.png`: Light模式图标 (1024x1024)
- `icon-dark.png`: Dark模式图标 (1024x1024)
- `icon-tint.png`: Tinted模式图标 (1024x1024)
- `Contents.json`: iOS 18兼容的配置文件

### 2. Legacy-AppIcon.appiconset (iOS 17及以下兼容)
- 传统多尺寸图标集（20pt-1024pt）
- 兼容旧版本Xcode和iOS系统

## 🔧 集成步骤

### 对于 iOS 18 项目（推荐）
1. 在 **Xcode 16** 中打开您的项目
2. 将 `AppIcon.appiconset` 文件夹拖拽到 Images.xcassets 中
3. 在 Attributes Inspector 中设置 Appearances 为 "Any, Dark, Tinted"
4. 三种变体会自动填充到对应槽位

### 对于 iOS 17 及以下项目
1. 使用 `Legacy-AppIcon.appiconset` 文件夹
2. 按传统方式集成到 Xcode 项目中

## 📋 iOS 18 技术要求
- **Xcode 版本**: 16.0 或更高
- **部署目标**: iOS 18.0 或更高
- **图标格式**: PNG，1024x1024，单一尺寸
- **兼容性**: 向下兼容 iOS 17 及以下
