# Linux 图标包说明

## 集成步骤
1. 将图标文件复制到适当的系统目录
2. 更新桌面文件 (.desktop) 中的图标引用
3. 刷新图标缓存

## 图标尺寸规范
- 16x16px: 用于小图标显示
- 22x22px: 用于面板图标显示
- 24x24px: 用于菜单图标显示
- 32x32px: 用于中等图标显示
- 48x48px: 用于大图标显示
- 64x64px: 用于大图标显示
- 128x128px: 用于大图标显示
- 256x256px: 用于大图标显示

## 注意事项
- 确保图标在所有尺寸下都清晰可见
- 避免使用过多细节，特别是在小尺寸版本中
- 遵循 Linux 的人机界面指南
