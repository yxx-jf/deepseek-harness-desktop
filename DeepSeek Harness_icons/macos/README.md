# macOS 图标包说明

## 集成步骤
1. 将图标文件添加到您的 Xcode 项目中
2. 在 Info.plist 中设置 CFBundleIconFile
3. 确保图标文件在应用程序包中

## 图标尺寸规范
- 16x16px: 用于小图标显示
- 32x32px: 用于中等图标显示
- 128x128px: 用于大图标显示
- 256x256px: 用于大图标显示
- 512x512px: 用于大图标显示
- 1024x1024px: 用于大图标显示

## 注意事项
- 确保图标在所有尺寸下都清晰可见
- 避免使用过多细节，特别是在小尺寸版本中
- 遵循 macOS 的人机界面指南
